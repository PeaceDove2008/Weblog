# PeaceDove Blog 更新日志

欢迎来到我的小窝！这里是 PeaceDove2008 的个人博客，一个**可爱粗野主义**（Cute Brutalism）风格的橙色系小站。

本站使用 [Fuwari](https://github.com/saicaca/fuwari)（基于 Astro 的静态博客模板）进行深度魔改，从主题配色到组件动效，全部重新设计。

## 本期更新内容

### 🎨 主题与风格
- **可爱粗野主义**风格：粗黑边框、硬阴影、糖果色卡片
- 橙黄色系配色（纸张淡黄背景 + 网格纸纹理）
- 背景水印：PeaceDove2008 空心大字装饰

### 🧩 页面功能
- 站点统计卡：文章数、总字数、阅读时长
- AI 作品展示卡：水彩小动物轮播图（5 秒切换）+ 流动字幕
- 标签贴纸系统：倾斜标签 + 悬停摇摆动效
- 头像卡片：QQ / 微信 hover 展示二维码，Bilibili / GitHub 直达

### 📄 页面结构
- 首页：文章卡片列表（糖果色轮换 + 分类徽章）
- 文章页：双层文字阴影标题、上一篇/下一篇导航
- 关于我、归档、赞助页面
